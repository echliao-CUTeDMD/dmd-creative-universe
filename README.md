# DMD 創意宇宙

中國科技大學數位多媒體設計系的獨立3D概念互動展館。參考系網內容製作，不是官方網站、實際校舍導覽或學生作品原件。

## 開啟與部署

在本資料夾執行 `python -m http.server 8773`，開啟 `http://localhost:8773/`。瀏覽器應支援 JavaScript 與 WebGL。不要依賴直接雙擊 HTML 的 file:// 模式，ES module 可能被瀏覽器封鎖。

上傳本資料夾所有檔案（包括 vendor）至 GitHub 儲存庫根目錄，於 Settings → Pages 選擇該分支及根目錄。無建置流程、無資料庫、無 API 金鑰。若放在子目錄，也可使用相對路徑正常載入。

## 功能

- 六個原創風格化3D展區，支援拖曳、縮放、點選物件或標籤與清單操作。
- 日夜切換、動畫暫停、減少動態偏好支援。
- 遊戲配色、動畫節奏、XR圖層、合成音試聽及作品星光互動。
- 六題學習挑戰、探索護照、本機進度保存與 JSON 匯出。
- 無WebGL時仍可讀內容及完成挑戰。外部官網連結需網路；3D套件已隨附，不需CDN。
- 未新增登入或連接深坑專案的 Supabase；本機進度不代表正式學分或證書。

## 內容維護

`app.js` 的 `zones` 定義展區、來源、題目及模型位置；`style.css` 為版面與行動版樣式；`index.html` 為入口。修改題目選項時應同步核對 answer 的零起算索引。
